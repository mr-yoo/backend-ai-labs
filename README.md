# Backend AI Labs

5주 과정 백엔드 AI 개발 실습 저장소. 각 주차에는 여러 개의 독립 실습을 추가한다.

## Week 02
- [Lab 01 — Spring Boot Hello World](week02/lab01-hello-world/README.md)

## GitHub Codespaces
1. 저장소의 **Code → Codespaces → Create codespace on main**을 선택한다.
2. 터미널에서 아래 명령을 실행한다.

```bash
cd week02/lab01-hello-world
mvn spring-boot:run
```

3. 포트 8080을 열고 `/hello` 경로를 확인한다.

개발 환경은 `.devcontainer/devcontainer.json`에서 관리한다.
